git status
这会列出哪些文件被修改了，哪些是新增加的。这能帮你检查是否有不小心改错的文件。

# 第一步：把所有修改过的文件添加到暂存区
git add .

# 第二步：提交更改并写下说明（建议写清楚你改了什么）
git commit -m "优化了特征融合模块的代码并调整了超参数"

# 第三步：推送到 GitHub 远程仓库
git push origin main
